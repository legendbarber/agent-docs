# Repository Map

> 요약: 코드 저장소의 비자명한 책임 경계·주요 진입점·수정 주의 경로를 찾는 선택적 지도. 전체 파일 목록이 아니다.
> 읽을 때: 코드 위치·책임 경계·진입점·수정 금지 경로가 코드 검색으로 불명확할 때만. 비코드 업무에서는 읽지 않는다.

## 작성 기준

- 디렉터리 이름만으로 역할이 명확하면 기록하지 않는다.
- 파일 단위 설명은 피하고, 책임 경계와 주요 진입점만 기록한다.
- 코드 검색으로 쉽게 확인 가능한 구현 세부사항은 기록하지 않는다.
- 생성 코드, 레거시 코드, 외부 연동 경계처럼 실수하기 쉬운 경로는 기록한다.
- 한 기능 흐름이 여러 디렉터리를 통과할 때만 흐름을 기록한다.

## Top-level areas

```text
<!--
apps/api/              # 외부 HTTP API와 요청 검증
packages/domain/       # 프레임워크에 의존하지 않는 핵심 비즈니스 규칙
packages/db/           # 스키마, 마이그레이션, 저장소 구현
generated/             # 생성 코드. 직접 수정 금지
-->
```
