# 문서 탐색 인덱스

> 요약: 현재 업무에 필요한 보조 문서의 위치와 열람 조건만 안내한다. 문서 본문을 복사하지 않는다.
> 읽을 때: `current-status.md` 등에서 필요한 문서 경로를 알 수 없고, 관련 참고 문서를 찾아야 할 때만.

| 경로 | 한 줄 요약 | 읽을 때 |
| --- | --- | --- |
| `agent-docs/current-status.md` | 활성 작업·단계·다음 행동의 짧은 인계 상태 | 모든 새 세션 시작 시 (인덱스 없이 직접 접근) |
| `agent-docs/plans/TEMPLATE.md` | 복합 작업 단계·완료 조건·최종 검증용 템플릿 | 새 복합 작업 계획을 생성할 때 |
| `agent-docs/plans/<task-id>.md` | 각 장기 작업의 실제 계획·검증·인계 상태 | 해당 작업을 수행·재개할 때; 경로는 `current-status.md`를 참조 |
| `agent-docs/decisions.md` | 오래 영향을 주는 주요 선택과 이유 | 선택 이유나 기존 제약을 확인할 때 |
| `agent-docs/repository-map.md` | 코드 책임 경계·진입점·주의 경로 | 코드 검색만으로 구조가 불명확할 때 |

## 관리 규칙

- 장기적으로 재사용할 문서만 **경로 / 짧은 요약 / 읽을 조건**을 등록한다. 일회성 산출물과 개별 작업 계획은 일괄 나열하지 않는다.
- 문서를 만들거나 내용의 목적이 바뀌면 인덱스의 관련 항목만 수정한다. 새 문서를 무조건 등록하지 않는다.
- 요약은 탐색용이며 실제 원문의 정확성·현재성을 대신하지 않는다. 필요한 원문과 자료는 별도로 확인한다.
- 인덱스가 길어지면 주제별 하위 인덱스로 분리하고, 상위 인덱스에는 진입 경로만 둔다.
