# 문서 탐색 인덱스

> 요약: 장기적으로 재사용할 선택적 문서의 **위치·용도·읽을 조건**만 알려주는 경량 색인.
> 읽을 때: 필요한 문서 위치가 `current-status.md`·현재 계획·직접 검색으로도 불명확할 때.

| 경로 | 요약 | 읽을 때 |
| --- | --- | --- |
| `agent-docs/plans/TEMPLATE.md` | 단계·완료 조건·최종 검증 계획 형식 | 새 복합 업무 계획을 생성할 때 |
| `agent-docs/context-maintenance.md` | 중복 제거·정보 압축·문서 정리의 안전 절차 | 주기적 집중 정리나 문서 노후화가 감지될 때 |
| `agent-docs/decisions.md` | 장기적으로 유지해야 할 결정과 이유 | 기술·운영 정책의 선택 이유가 필요할 때 |
| `agent-docs/repository-map.md` | 코드 책임 경계·진입점·수정 주의사항 | 코드 검색으로 구조가 불명확할 때 |

활성 작업의 개별 계획은 `current-status.md`의 경로로 직접 연다. 이 색인에 모든 계획·일회성 결과물을 나열하지 않는다. 문서를 추가·이동하면 관련 항목만 수정하고, 원문을 복사하지 않는다.
